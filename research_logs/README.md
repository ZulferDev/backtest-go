# Research Logs Directory Structure

This directory stores AI-generated strategies and their iteration history.

## Directory Structure

```
research_logs/
├── .template/                    # Templates for new strategies
│   ├── hypothesis.md            # Hypothesis template
│   ├── strategy_template.go     # Strategy code template
│   ├── memory.json              # Memory template
│   └── analysis.json            # Analysis template
│
└── {strategy_id}/               # One directory per strategy
    ├── hypothesis.md            # Initial hypothesis
    ├── strategy_v1.go           # Version 1 code
    ├── strategy_v2.go           # Version 2 code (after refinement)
    ├── strategy_current.go      # Symlink to latest version
    ├── results_v1.json          # Backtest results v1
    ├── results_v2.json          # Backtest results v2
    ├── analysis_v1.json         # Structured analysis v1
    ├── analysis_v2.json         # Structured analysis v2
    ├── memory.json              # Accumulated learning
    └── validation_errors.log    # AST/Test errors (if any)
```

## File Purposes

### hypothesis.md
- Initial market observation and thesis
- Success criteria
- Expected edge and risk management
- Created during CONCEIVE phase

### strategy_vN.go
- Go code implementing the strategy
- Must implement `pkg/sdk.Strategy` interface
- Includes `// RATIONALE:` comments
- Created during WRITE phase

### results_vN.json
- Backtest execution results
- Metrics: PnL, Sharpe, drawdown, trades
- Generated by backtest engine
- Created during BACKTEST phase

### analysis_vN.json
- Structured analysis of backtest results
- Hypothesis validation
- Identified weaknesses
- Next iteration plan
- Created during ANALYZE phase

### memory.json
- Persistent learning across iterations
- Strategy lineage with version history
- Learned patterns (what works)
- Failed approaches (what doesn't work)
- Updated after each ANALYZE phase

### validation_errors.log
- Compilation errors
- AST validation errors
- Test failures
- Used for error recovery

## Workflow

1. **Init**: Create directory structure for new strategy
2. **CONCEIVE**: Write hypothesis.md
3. **WRITE**: Generate strategy_v1.go
4. **LINT**: Validate with AST checker, log errors if any
5. **TEST**: Run unit tests, log failures if any
6. **BACKTEST**: Execute and generate results_v1.json
7. **ANALYZE**: Generate analysis_v1.json, update memory.json
8. **REFINE**: Generate strategy_v2.go based on analysis
9. **Repeat**: Steps 4-8 for each iteration

## Usage

Create new strategy:
```bash
go run cmd/orchestrator/main.go init --strategy-id "my_strategy"
```

This will create:
- `research_logs/my_strategy/` directory
- Copy templates for hypothesis and memory
- Ready for CONCEIVE phase
